# 🎓 Student Record Management System

A beginner-friendly **Student Record Management System** developed in **C** as a first-semester BCA project.

The program provides a simple menu-driven interface for managing student records.

## ✨ Features

* ➕ Add a student
* 📋 Display student records
* 🔍 Search for a student
* ✏️ Update student information
* 🗑️ Delete student records
* 📊 Calculate student results
* 📈 Sort students by percentage
* 💾 Save student records to a file
* 📂 Load saved records when the program starts

## 🛠️ Technologies Used

* **Language:** C
* **Compiler:** GCC
* **IDE:** Visual Studio Code
* **Version Control:** Git & GitHub

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/dushyant-cloud/Student-Record-Management-System.git
```

### 2. Open the project folder

```bash
cd Student-Record-Management-System
```

### 3. Compile the program

```bash
gcc student_management.c -o student_management
```

### 4. Run the program

On Windows:

```bash
.\student_management.exe
```

On Linux/macOS:

```bash
./student_management
```
